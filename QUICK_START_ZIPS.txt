=============================================================================
QUICK START: ZIP Creation Script
=============================================================================

AUTOMATIC USAGE (via Makefile):
    make all                            # Generates all files AND creates ZIPs

MANUAL USAGE:
    python3 create_zips.py              # Update all ZIPs as needed
    ./create_zips.py                    # Same (if executable)

COMMON OPTIONS:
    -n, --dry-run                       # Show what would happen
    -v, --verbose                       # Show detailed progress
    -h, --help                          # Show help

OUTPUT FILES (co-located with source files):
    results/BSB_usfm.zip                # Main USFM files
    results/int/BSB_int_usfm.zip        # Interlinear version
    results/strongs/BSB_strongs_usfm.zip     # With Strong's numbers
    results/strongs_full/BSB_full_strongs_usfm.zip  # Full Strong's version
    
    results_usj/BSB_usj.zip             # Main USJ files
    results_usj/int/BSB_int_usj.zip     # Interlinear version
    results_usj/strongs/BSB_strongs_usj.zip  # With Strong's numbers
    results_usj/strongs_full/BSB_full_strongs_usj.zip  # Full Strong's version

NAMING CONVENTION:
    ZIP files are named with: PREFIX_EXTENSION.zip
    - PREFIX: Common prefix from filenames (e.g., "BSB", "BSB_int")
    - EXTENSION: File extension of zipped files (e.g., "usfm", "usj")
    
    Examples:
    - Files: GEN.usfm, EXO.usfm → BSB_usfm.zip
    - Files: 01GENBSB_int.usfm → BSB_int_usfm.zip
    - Files: GEN.usj, EXO.usj → BSB_usj.zip

SMART UPDATES:
    The script only updates a ZIP if at least one source file is newer
    than the existing ZIP file. This makes it fast for repeated runs.

KEY FEATURES:
    ✓ All ZIP files are created in the SAME DIRECTORY as their source files
    ✓ ZIP names include file extension for easy identification
    ✓ Efficient timestamp-based updates (only rebuild when needed)
    ✓ Complete regeneration ensures integrity
    ✓ Automatically runs as part of 'make all' workflow

MAKEFILE INTEGRATION:
    The script is called automatically at the end of 'make all'.
    After all USFM and USJ files are generated, ZIPs are created/updated.
    No manual intervention needed for the normal build process!

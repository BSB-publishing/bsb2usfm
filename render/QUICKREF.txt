📋 QUICK START (5 Minutes)
──────────────────────────────────────────────────────────────

STEP 1: Test Locally ✅
  $ docker-compose up -d web
  $ open http://localhost:5000
  # Test conversion → Download ZIP → Verify
  $ docker-compose down

STEP 2: Push to Git ✅
  $ git add .
  $ git commit -m "Ready for Render"
  $ git push origin main

STEP 3: Deploy on Render.com ✅
  • Go to: https://render.com
  • Sign up with GitHub/GitLab
  • Click: New + → Web Service
  • Select: Your repository
  • Choose: Docker environment
  • Select: Free plan
  • Set health check: /health
  • Click: Create Web Service
  • Wait: 5-10 minutes
  • Done! 🎉

STEP 4: Test Deployment ✅
  $ curl https://your-app.onrender.com/health
  # Should return: {"status":"healthy","environment":"production"}

🆘 TROUBLESHOOTING
──────────────────────────────────────────────────────────────

Build Fails:
  → Test locally: docker-compose build web
  → Check Render logs in dashboard

Service Won't Start:
  → Test locally: docker-compose up web
  → Check health: curl http://localhost:5000/health
  → Review Render logs

Conversion Fails:
  → Test locally with same options
  → Check memory usage (512MB limit)
  → Review logs during conversion

Slow Performance:
  → Normal on free tier (shared CPU)
  → Conversion takes 3-5 minutes
  → Consider upgrading to paid tier

Service Sleeping:
  → Normal behavior on free tier
  → Sleeps after 15 min inactivity
  → First request takes ~30s to wake

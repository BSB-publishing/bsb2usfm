# DBL Adaptations

The script `adapt_usx_for_DBL.py` modifies USX files generated by
`bsb2usfm.py` to pass Digital Bible Library (DBL) validation. This is
the USX-side counterpart to `adapt_usfm_for_paratext.py` (see
[PARATEXT_ADAPTATIONS.md](PARATEXT_ADAPTATIONS.md)); the two scripts
run on different serializations of the same source tree and fix
different validators' complaints, so they're documented separately.
The unmodified files under each edition's `results_usx/` directory
(e.g., `bereanbible/results_usx/`) retain the full original content.

## Adaptations

### 1. `<ref loc="...">` elements converted to plain text

**What changes:** `<ref loc="BOOK C:V">Display Text</ref>` elements
inside `<para style="r">` (parallel passage reference) paragraphs are
unwrapped to their display text, dropping the `<ref>` element and its
`loc` attribute.

**Example:**
```
Before: <ref loc="LUK 24:36-49">Luke 24:36–49</ref>
After:  Luke 24:36–49
```

**What is preserved:** The human-readable reference text is kept
unchanged. The machine-readable `loc` target (e.g., `LUK 24:36-49`),
which DBL's validator does not accept in this context, is discarded —
the same trade-off `adapt_usfm_for_paratext.py` makes when converting
`\ref` markers on the USFM side (see that document's item 1). Following
that document's convention, this is classified as **non-lossy**: no
visible content is lost, only the structured link target.

This affects several thousand references across both editions (6,300+
in a full majoritybible build, including the mirrored BSB Old
Testament books).

### 2. Strong's number padding

**What changes:** Strong's numbers are zero-padded to 5 digits (e.g.,
`H776` becomes `H00776`, `G123` becomes `G00123`). USX requires Strong's
IDs in the form `H#####`/`G#####`.

**What is preserved:** No information is lost — this is purely a
formatting fix, identical in effect to the same fix in
`adapt_usfm_for_paratext.py`.

## Lossy Adaptations

None. Unlike the Paratext pipeline, `adapt_usx_for_DBL.py` does not
remove any paragraphs or references outright — see
[PARATEXT_ADAPTATIONS.md](PARATEXT_ADAPTATIONS.md#lossy-adaptations)
for the two lossy changes that exist on the Paratext `.sfm` side only
(a non-verifiable `\r` line in Hebrews, and non-canonical `\xt`
references converted to plain text). Those changes are specific to
`adapt_usfm_for_paratext.py` and are not applied to the USX/DBL output.

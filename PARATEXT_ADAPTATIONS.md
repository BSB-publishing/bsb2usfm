# Paratext Adaptations

The script `adapt_usfm_for_paratext.py` modifies USFM files generated by
`bsb2usfm.py` to pass Paratext's Basic Checks validation. Nearly all
adaptations are **non-lossy** — they restructure markers without losing
content. The only lossy changes affect a single `\r` line and references
to non-canonical books (5 total). The unmodified files under each
edition's `results/` directory (e.g., `bereanbible/results/`) retain the
full original content.

## Non-Lossy Adaptations

### 1. `\ref` markers converted to `\xt`

**What changes:** Custom `\ref` markers are converted to `\xt`
(cross-reference text), the standard USFM marker for scripture references.
Inside footnotes, `\xt` is used directly. Outside footnotes (in `\r`
lines), `\ref` is converted to plain text.

**Example (in footnote):**
```
Before: \ft see \ref 1 Chronicles 2:9–10|1CH 2:9-10\ref*.
After:  \ft see \xt 1 Chronicles 2:9–10\xt*.
```

**What is preserved:** The cross-reference semantics are preserved via the
`\xt` marker (1,250+ references across all books). The machine-readable
reference target (e.g., `JHN 1:1-5`) is discarded, but the human-readable
reference text and its semantic role as a cross-reference are kept.

### 2. `\wj` markers split at verse boundaries (Words of Jesus)

**What changes:** `\wj ... \wj*` markers that span multiple verses are
split so each verse has its own properly-contained `\wj ... \wj*` span.
Red-letter text is preserved.

**Example:**
```
Before: \wj Come to Me, all who are weary. \v 29 Take My yoke upon you.\wj*
After:  \wj Come to Me, all who are weary.\wj* \v 29 \wj Take My yoke upon you.\wj*
```

**What is preserved:** The red-letter distinction for Jesus' spoken words.
The original USFM has `\wj` spans that wrap multiple verses, which causes
Paratext to generate `<unmatched marker="wj*" />` validation errors.
Splitting at verse boundaries resolves this while keeping the markup.

### 3. `\pmo` converted to `\lf` (list footer)

**What changes:** `\pmo` (embedded text opening) markers are converted to
`\lf` (list footer) markers.

**Example:**
```
Before: \pmo \v 9 The total number of men in the divisions of the camp of Judah is 186,400
After:  \lf \v 9 The total number of men in the divisions of the camp of Judah is 186,400
```

**What is preserved:** The `\lf` marker is the USFM marker designed for
"concluding remarks that are part of list content but are not list items" —
exactly what these census totals are. Paratext flags `\pmo` as "Marker
cannot occur here" in list contexts because `\pmo` is not allowed after
`\li1`/`\li2` list items, while `\lf` is valid at the same level.

### 4. `\mt2` + empty `\mt1` collapsed to `\mt1`

**What changes:** The `\mt2 BookName` line followed by an empty `\mt1`
line is collapsed into a single `\mt1 BookName` line. Books with actual
two-level titles (Song of Songs, Acts, Revelation, Ecclesiastes) are
preserved as-is since both `\mt2` and `\mt1` have content.

**Example:**
```
Before:
\mt2 Genesis
\mt1
\c 1

After:
\mt1 Genesis
\c 1
```

**What is preserved:** No content is lost — the empty `\mt1` carried no
text. The promotion from `\mt2` to `\mt1` satisfies Paratext's requirement
for a `\mt` or `\mt1` marker before chapter 1.

### 5. Empty `\q1` and `\p` lines removed

**What changes:** Standalone `\q1` or `\p` lines that contain no text are
removed.

**What is preserved:** These empty markers are redundant — they are always
preceded by `\b` (blank line) or section headings that already provide the
visual separation. No content or meaningful spacing is lost.

### 6. `\mr` converted to `\d`

**What changes:** `\mr` (major section reference range) markers are
converted to `\d` (descriptive title) markers. This affects only
Habakkuk 3:19.

**Example:**
```
Before: \mr For the choirmaster. With stringed instruments.
After:  \d For the choirmaster. With stringed instruments.
```

**What is preserved:** The `\d` marker is the standard USFM marker for
musical and liturgical directions — the same marker used for identical
superscriptions throughout the Psalms. This is arguably the more correct
marker for this content.

### Other non-lossy fixes

- **Strong's number padding:** Numbers are zero-padded to 5 digits
  (e.g., `H776` becomes `H00776`). No information is lost.
- **Trailing empty `\ft` removed:** Empty `\ft` markers before `\f*` at
  the end of footnotes are removed. No content is lost.
- **Empty `\fqa` before `\fv` removed:** Empty `\fqa` markers that
  immediately precede `\fv` verse number markers in footnotes are removed.
  No content is lost.

## Lossy Adaptations

Only two minor lossy changes remain:

### 1. One `\r` line removed (Hebrews)

The `\r (Joshua–Malachi)` line in Hebrews is removed because it is a
book-only range with no chapter:verse reference, which Paratext cannot
validate. All other `\r` parallel passage references are preserved.

### 2. Non-canonical book references converted to plain text

References to non-canonical books (Jasher, 1 Enoch) inside footnotes are
converted from `\xt` to plain text to avoid Paratext "Invalid book" errors.
This affects 5 references across 4 books (Joshua, 2 Timothy, 2 Peter,
Jude). The reference text is preserved — only the `\xt` markup is removed.

## Remaining Paratext Warnings

The following warnings are **not addressed** by this script because they
are intentional or require Paratext project configuration:

- **"#Verse missing"** — Certain verses (e.g., Matthew 17:21, Mark 7:16)
  are intentionally omitted in the BSB/MSB because they follow the critical
  text. The omitted verses are noted in footnotes. A `custom.vrs` file
  under each edition's `sfm_for_paratext/` directory (e.g.,
  `bereanbible/sfm_for_paratext/`) is provided that lists these as
  excluded verses so Paratext accepts the intentional omissions.
- **"seed-bearing" non-wordforming characters** — Hyphenated compound
  words inside `\w` markers. This is a Paratext project setting issue
  (configure hyphen as word-forming character).

### Quotation Check Warnings

Paratext's Quotation Check may report thousands of warnings (including
"Unexpected quotation mark value" for every quote in the text). These are
**not** problems with the USFM text — both editions use standard English
typographic quotation marks correctly. The warnings occur because the
Paratext project's Quotation Rules have not been configured. Follow the
steps below to resolve them.

#### Step 1 — Configure Quote Marks

Open **Project menu** (`≡`) > **Project Settings** > **Quotation Rules**
and enter the following values (you must be a project Administrator):

| | Opening | Closing | Continuer |
|---|---|---|---|
| **Level 1** | `"` (U+201C) | `"` (U+201D) | `"` (U+201C) |
| **Level 2** | `'` (U+2018) | `'` (U+2019) | `'` (U+2018) |
| **Level 3** | `"` (U+201C) | `"` (U+201D) | `"` (U+201C) |

The **continuer** is the mark placed at the start of a new paragraph when
a quotation carries over from the previous paragraph. In English the
continuer is the same character as the opener.

**Tip:** Copy and paste the characters from the table above directly into
the Paratext dialog fields rather than trying to type them from the
keyboard.

#### Step 2 — Configure Apostrophe as Word-Medial Punctuation

The right single quotation mark `'` (U+2019) serves double duty in
English: as a closing single quote and as an apostrophe (e.g., "don't",
"Israel's"). Without this step Paratext flags every apostrophe as an
unexpected closing quote.

Open **Project menu** (`≡`) > **Language Settings** > **Other Characters**
tab and add the following to the **Word-medial punctuation** field:

- `'` (U+2019, right single quotation mark / apostrophe)
- `-` (hyphen, for compound words like "seed-bearing")

#### Step 3 — Re-run the Quotation Check

Go to **Checking** > **Run Basic Checks**, select **Quotations**, and run
the check. The vast majority of the previous warnings should now be
resolved. Any remaining warnings are genuine quotation issues worth
reviewing individually.
